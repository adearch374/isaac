How it works

  • Prepare a file (.csv, .xlsx or .xls) with these columns: First Name, Last Name, Class, Date of Birth, Gender.
  • Optional LIN column: include it to assign your own Learners Identification Numbers (the student's ID in the system). Leave it blank to have one generated automatically. Every LIN must be unique — duplicates are skipped and reported.
  • Column headers are matched ignoring capitalisation and common aliases (so class, CLASS and Class all work), and the order of the columns does not matter. First Name, Last Name and Class columns are required — a file without them is rejected immediately with a message listing the columns found.
  • The Class value must already exist in the system (see the list below; spaces and capital letters are ignored, so JSS1 matches JSS 1). Date of Birth accepts 2012-05-14 or 14/05/2012.
  • Usernames and passwords are generated automatically. After uploading, a file generated_student_credentials.csv downloads immediately with every student's login details — save it and hand the credentials to the students.
  • Passwords are stored securely (hashed) in the database; they appear only in that downloaded file, so keep it safe.
  • Rows with problems (missing names, unknown class) are skipped and listed in the download's Status column — fix them and upload again; already-created students are not duplicated. After the download, a green/red summary banner appears on the next page you open showing how many students were created and how many rows need fixing.

Maximum 1000 students per upload. The total upload size is limited to 10 MB.
